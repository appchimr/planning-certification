# Certification HAS 2028 — CHIMR

Application GitHub Pages avec sauvegarde centrale Google Sheets.

- `index.html` : vue utilisateurs, lecture seule.
- `admin.html` : interface Qualité / administration.
- `Code.gs` : backend Google Apps Script.
- `config.js` : URL du déploiement Apps Script.
- `common.js` : rendu commun du planning.
- `public.js` : chargement et rafraîchissement de la vue utilisateurs.
- `admin.js` : modifications et synchronisation centrale.
- `style.css` : charte visuelle.
- `logo-chimr.jpg` : logo CHIMR.

Le Google Sheet reste privé sur le compte Communication CHIMR.
